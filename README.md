## 👨‍💻 About me

- 🧩 I ship **business apps** for real shops & clinics — point-of-sale, debt tracking, clinic management, order tracking.
- 🌐 Everything **Arabic-first & RTL**, designed for the tools people around me actually use.
- 🖥️ I like **self-hosting**: Next.js behind Caddy, Docker, DuckDNS — full control, no vendor lock-in.
- 🛠️ I also build **developer tools** (like [Athar](https://github.com/AbuDergham/Athar), a cross-agent AI-chat finder).
- 📫 Reach me on GitHub — issues & discussions are open.
